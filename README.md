# Guia de IAs — dados

Arquivo de dados do app Android **Guia de IAs**.

- `ias.json`: lista de IAs, como usar, planos e preços.
- O app baixa este arquivo ao abrir e ao tocar em ⟳.
- Para atualizar um preço: edite o `ias.json` aqui no GitHub e mude o campo `"atualizado"`.

Preços em US$ são convertidos no app pela cotação do dia + IOF.
